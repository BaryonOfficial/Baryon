# Documentation Map

This directory is the Mintlify docs root for the public repo.

When Mintlify is connected to `BaryonOfficial/Baryon`, configure the Git
subdirectory path as `/docs`. The required site config lives at
[`docs.json`](docs.json), so the public branch Mintlify builds, including
`main`, must contain this directory.
