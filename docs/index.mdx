Baryon is a real-time cymatic audio visualizer. These docs cover first-session use, creative capture workflows, the engine architecture, runtime contracts, the full control reference, and frequently asked questions.

## Start here

- [First session guide](/public/guides/first-session): connect audio, frame the scene, set rotation, and save a repeatable setup.
- [Understanding the engine](/public/guides/understanding-the-engine): learn what Baryon is rendering and how the main settings affect the field.
- [Creative workflows](/public/guides/creative-workflows): use nature recordings, capture stills or video, and understand current 3D export limits.
- [Control panel reference](/public/reference/controls): review the current controls exposed by the Baryon GUI.
- [FAQ](/public/reference/faq): answer common product and licensing questions.
- [Architecture map](/public/architecture/system-overview): find the shared engine seams and ownership boundaries.
- [Contracts and boundaries](/public/architecture/contracts): understand the stable engine contracts such as `AudioFeatureFrame`, controls, persistence, and render-profile policy.

## How these docs are organized

- **Guides** walk you through using Baryon, from your first session to creative capture workflows.
- **Architecture** maps the open engine for developers reading or extending the source.
- **Reference** is the exhaustive control panel and FAQ.

New to Baryon? Start with the [first session guide](/public/guides/first-session). Want to know what it is actually rendering? Read [Understanding the engine](/public/guides/understanding-the-engine).
