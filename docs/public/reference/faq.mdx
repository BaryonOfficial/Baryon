title: Baryon FAQ
description: Frequently asked questions from the Baryon marketing site.
---

## Do I need to install anything to try it?

No. The full engine runs in a WebGPU browser at app.baryon.live. Open the page and connect an audio source: an audio file, BlackHole on macOS, VB-Cable on Windows, or PipeWire/PulseAudio routing on Linux.

## Which browsers does it work in?

Use a Chromium-based browser with WebGPU enabled: Chrome, Edge, Brave, Arc, Opera, or Vivaldi. Safari and Firefox support is still uneven. Baryon Desktop ships with Electron/Chromium.

## Is it really physics-based?

Yes. Audio resolves into a modal cymatic field with openly stated assumptions. It is not a bar graph, a waveform, or a beat-reactive shader.

## What audio inputs work?

Microphone, loopback, line input, or an audio file — with Voice and Ambient input profiles tuned for different material.

## Can I use nature recordings like water, wind, trees, or animals?

Yes. Use **Ambient** for layered field recordings such as water, wind, trees, room tone, or mixed natural soundscapes. Use **Voice** when the source has one clear lead tone, such as a voice, chant, or isolated call. See [Creative workflows](/public/guides/creative-workflows) for a starting point.

## How do I learn what the settings actually mean?

Start with [Understanding the engine](/public/guides/understanding-the-engine), then use the [Control panel reference](/public/reference/controls) for exact control definitions. The short version: audio excites a continuous modal field; the controls shape analysis, field response, rendering, movement, and camera view.

## Can I set keyboard shortcuts for manual rotation?

Not currently. Manual cymatic rotation is controlled through **Rotation Mode** and **Manual Rotation** in the GUI. Camera movement uses the floating camera controls and orbit drag when the camera is unlocked.

## Is Baryon rendering a point cloud?

No. Baryon renders a continuous volumetric modal field. The visible structure is sampled by the renderer; it is not stored as a point-cloud model.

## Can I export coordinates, a mesh, or a 3D-printable model?

Not from the current public app. Baryon does not currently export raw coordinates, point clouds, STL, OBJ, GLTF, or slicer-ready geometry. A future 3D export would need to freeze a moment in time, sample the field, extract a surface or volume, and convert it into watertight geometry. See [Creative workflows](/public/guides/creative-workflows).

## Can I export still images or videos?

There is no native still-image export button today. Use your browser or operating system capture tools after framing the scene. For cleaner captures, lock the camera and set **Rotation Mode** deliberately before recording or taking a screenshot.

## What will the desktop app add, and when?

Stage output, multi-surface operation, and repeatable show setups. It is launching soon; the waitlist gets beta invites first. Spout and NDI routing are on the roadmap.

## Can I use Baryon in a commercial show or product?

Yes. A desktop license covers using Baryon as your performance instrument in paid shows, festivals, and client gigs. A separate commercial license is only needed if you ship Baryon inside a product, redistribute it, embed it in another system, run it as a hosted service, or deploy it across an organization.

## Is the engine open?

The source is public on GitHub — read the physics, inspect the render path, file issues, and build on the primitive.
