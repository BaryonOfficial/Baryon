Baryon Desktop runs the same WebGPU cymatic engine as the [web app](https://app.baryon.live),
packaged for the stage: lower-latency live input, output to your existing video
setup, and controls built for performing rather than evaluating.

<Info>
  Baryon Desktop 1.2.0 adds two-way OSC/MIDI control, TouchDesigner control and
  structure components, expanded visual controls, and synchronized Performer
  output. Read the [1.2.0 release notes](/public/desktop/release-notes) before
  upgrading a show setup.
</Info>

## Free to explore, paid to perform

The app itself is **free to download and evaluate** — no account required. You can
open it, feed it audio or a microphone, and run the full real-time visualizer to
decide whether it belongs in your show.

An active **Baryon Pro entitlement** unlocks professional live use: Performer
Mode, fullscreen Display output, Syphon or Spout publishing, OSC/MIDI control,
and the right to use Baryon in paid shows. The 10-day Pro trial includes those
rights for its active term. See [Plans & licensing](/public/desktop/licensing)
for the full breakdown.

Free Listener Mode covers evaluation and personal use. An active Baryon Pro
entitlement, including the trial, covers professional performance.

## Same engine as the web app

Desktop and web share the same render engine and core visual controls. Their
output controls differ: the web app and Listener Mode can render a transparent
background, while Performer always sends an opaque image over black. The
hands-on guidance in the **Using Baryon** track applies to both unless a guide
marks a host-specific control.

## What to expect

- **Platforms:** macOS, Windows, and Linux. Listener Mode runs on all three;
  Performer Mode (stage output, OSC/MIDI) is macOS and Windows today and is
  coming to Linux later.
- **Program output:** send Performer fullscreen to another display on macOS or
  Windows, or publish it through Syphon on macOS or Spout on Windows. One
  destination is active at a time.
- **Output appearance:** Performer output is always opaque and black-backed. In
  a receiving tool, use Add or Screen blending when black should disappear.
- **Offline-friendly licensing:** your license is verified locally, so a network
  outage at a venue never blocks a performance. See [Plans &
  licensing](/public/desktop/licensing).
